# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
・リモートリポジトリは、GitHubなどのサーバー上に保存されているリポジトリです。
・ローカルリポジトリは、自分のパソコン内に保存されているリポジトリです。


## プッシュとマージの違いは何でしょうか？
・プッシュは、ローカルリポジトリの変更内容をリモートリポジトリへ反映することです。
・マージは、異なるブランチの変更内容を1つのブランチへ統合することです。


## コミットとプッシュの違い
・コミットは、ローカルリポジトリに変更履歴を保存する操作です。
・プッシュは、コミットした内容をリモートリポジトリへ反映する操作です。


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
・「修正」などの曖昧な表現ではなく、具体的な内容を記載します。


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
・ローカルでマージする場合は、自分の環境で直接ブランチを統合します。
・プルリクエストでマージする場合は、コードレビューを受けてから統合できます。


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
・コンフリクトが発生したファイルを確認する。
・どちらの変更を残すか判断して修正する。
